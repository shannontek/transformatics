# Textbook surface: Read

The user asked for a much plainer, early personal-web / GeoCities style on
8 September 2026. This replaces the previous monograph sidebar design.
The root design.md is the current working instruction source; never overwrite it for UI work.

Use white paper, black Times text, ordinary blue underlined links, purple
visited links, horizontal rules and native controls. Keep the page in one
column with a compact header and a native All chapters disclosure. No fixed
sidebar, oversized headline, marketing hero, decorative cards or animation.
Dark appearance remains an explicit saved preference; a fresh visit is white.
Preserve readable line lengths, local equation scrolling and phone layouts.

Animations teach a specific calculation. The 2D shear/translation example
shows composition order with exact coordinate and observable readouts. The
3D laboratory evolves its existing finite Fourier approximation and identifies
its limits. Both start paused, have usable controls, and work without relying
on motion to convey the explanation. Do not imply either certifies a proof.

Human readers have equations, examples and exercises. Agents have the same
Markdown, source links and hash-pinned claim JSON. Mathematical scopes, claim
boundaries, keyboard access, answer disclosures, print and download remain
part of the product. The public Pages workflow deploys the built edition on
`main` and manual dispatch after the textbook checks pass. ROOT and E-prime
are OPEN; FORCED-D is IMPORTED with the scope in docs/STATUS.md. Unsolved
research remains paused.
